# 🃏 لعبة تركس الجماعية (Trix Online Game)

لعبة تركس جماعية تفاعلية تعمل عبر المتصفح والهواتف الذكية بنظام الوقت الفعلي (Real-time) باستخدام Node.js و Socket.io، مصممة خصيصاً لتجربة مستخدم سلسة وعمودية (Vertical Layout).

## ✨ المميزات الرئيسية
* **لعب جماعي وفردي:** إمكانية إنشاء غرف خاصة والانضمام إليها عبر كود الغرفة، أو اللعب الفردي ضد الذكاء الاصطناعي.
* **التصميم العمودي (Vertical Layout):** مصمم خصيصاً للشاشات العمودية لتجربة لعب مريحة على الهواتف المحمولة.
* **دعم العقود الكاملة:** تدعم عقود تركس الشهيرة (شيخ الكبة، البنات، الديناير، اللطوش، وتركس).
* **نظام تفاعلي متكامل:** إرسال إيموجي، جدول نقاط تفصيلي، وحفظ حالة اللعبة محلياً (LocalStorage).
* **مؤثرات صوتية واهتزازات:** تعزيز تجربة اللعب بـ Web Audio API و Vibration API.

## 🛠️ التقنيات والبرمجيات المستخدمة
1. واجهة المستخدم (Frontend)
HTML5 & CSS3: لهيكلة اللعبة وتصميم واجهة تفاعلية عمودية متوافقة تماماً مع الهواتف الذكية (Mobile-First) باستخدام CSS Grid و Flexbox.

Vanilla JavaScript (ES6+): لإدارة منطق اللعبة بالكامل، توزيع الأوراق، التحقق من صحة الحركات، ومحاكاة الذكاء الاصطناعي للاعبين الوهميين.

Web Audio API: لتوليد مؤثرات صوتية تفاعلية (أصوات سحب ورمض الأوراق والنقاط) دون الحاجة لملفات خارجية.

Socket.io Client: للاتصال الفوري والتزامن اللحظي مع سيرفر اللعبة عبر الـ WebSockets.
2. الخادم والBackend (Backend & Server)
Node.js: بيئة تشغيل جافاسكربت على الخادم.

Express.js: إطار عمل خفيف لإدارة مسارات الخادم الأساسية.

Socket.io: لإدارة الغرف، استقبال أحداث اللعب من اللاعبين وتوزيعها بشكل فورى (Real-time multiplayer).
